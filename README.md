# 🏎️ racing-games

ブラウザで遊べる 3D レースゲーム集です。iPhone・iPad・パソコンの Safari / Chrome でそのまま動きます。
インストールは不要ですが、ホーム画面に追加するとアプリのように全画面で遊べます。

## APEX RACING

写真の質感を使ったリアルなグラフィックで、5台のライバル車と競う本格レースゲームです。

- **車（7種類）**
  - GTクーペ／スーパーカー／ラリー／クラシックGT／フォーミュラ／ツーリングカー／オープンスポーツ
  - 加速・最高速・曲がりやすさが、車ごとに違います。
  - ボディの色は9色から選べます。
- **ドリフト＆ブースト**
  - ドリフトを長く続けるほど、ブーストゲージがたまります。
  - ドリフトを抜けると、ゲージの分だけ加速します。
- **コース（3つ）**
  - 標準サーキット（森の中）
  - シティ・サンセット（夕焼けの市街地）
  - シーサイド（海ぞいの高速コース）
- **オリジナルコース**
  - 自分でコースを描いて走れます。
  - 作ったコースは「コード」や「リンク」で友達に送れます。
  - 合言葉を入れると、iPhone と iPad など別の端末どうしで、コースが自動で同じになります。
- **レースの設定**
  - モード：レース（AI 5台）／タイムアタック
  - 難易度：やさしい・ふつう・むずかしい
  - 周回：1・3・5周
- **タイムランキング**
  - コースごとに、ベストラップの TOP10 を記録します。
  - 10位以内に入ると、アルファベット3文字で名前を残せます。
- **ゴール演出とリプレイ**
  - ゴールすると派手な演出のあと、自動でリプレイが始まります。
  - リプレイのカメラは5種類あり、スローでも見られます。
- **BGM**：4曲から、ランダムで流れます。
- **画質**：「きれい」と「かるい」を切りかえられます。動きがカクつくときは「かるい」にしてください。

## TURBO DRIVE（がくしゅうモード）

APEX RACING と同じ車・グラフィックで、**レースしながら勉強できる**モードです。

- コースを走っていると、画面の上に問題が出ます。問題は読み上げもします。
- 少し先に、答えが書かれた3つのゲート（青・緑・オレンジ）が出てきます。
  - 正解のゲートを通る → **NITRO（ニトロ）** で一気に加速します。
  - まちがえる → スピードが落ちて、同じ問題がもう一度出ます。
  - 2回まちがえると、正解のゲートが光ってヒントになります。
- 正解すると ⭐ がたまります。正解が続くと COMBO になり、問題はだんだん難しくなります。
- コースは、ハンドル操作がいそがしいテクニカルコースが3つです。
  - 峠のヘアピン
  - テクニカル市街地
  - S字コースト

| 学年 | 問題の種類 |
|---|---|
| 1年生 | たし算・ひき算（20まで）／かずのしくみ（10のまとまり・つぎのかず・いちばん大きいかず）／1年生のかん字／とけい（なんじ・なんじはん） |
| 2年生 | かけざん（九九）／2けたのたし算・ひき算（くり上がり・くり下がり）／1・2年生のかん字／とけい（なんじなんぷん） |
| 3年生 | わり算（あまりあり）／3けたのたし算・ひき算・2けた×1けた／3年生のかん字／時こくと時間（○ぷんあと・なんぷんかん） |

どの学年でも「ぜんぶ ミックス」を選べます。

## 🎮 そうさ方法

| | iPhone・iPad | キーボード | ゲームパッド |
|---|---|---|---|
| ハンドル | ◀ ▶ ボタン、または本体を傾ける（傾きでハンドル） | ← → / A D | 左スティック |
| アクセル | アクセル | ↑ / W | RT |
| ブレーキ・バック | ブレーキ | ↓ / S | LT |
| ドリフト | ドリフト | Space | A |
| その他 | 画面右上のボタン | C カメラ ／ M BGM ／ P ポーズ ／ R コースに戻る | |

- **傾きでハンドル**：スタート画面で選び、センサーの確認で「許可」を押します。🧭 ボタンで、今の傾きを「まっすぐ」に合わせなおせます。
- **縦向きロック中でも横で遊べる**：iPhone の画面ロックは縦向きにしか固定できません。そこで、スタート画面の「📱 横向きで遊ぶ」を押して「許可」すると、スマホを横に持ったときにゲームの画面が自動で回ります。

## 📱 ホーム画面に追加する（iPhone・iPad）

1. Safari で、遊びたいゲームの URL を開きます。TURBO DRIVE なら `turbo-drive.html` です。
2. 共有ボタン →「ホーム画面に追加」を押します。

APEX と TURBO は、別々のアイコン・名前で追加されます。一度開けば、電波がなくても遊べます。

## 💾 記録について

- タイムランキング・ベストラップ・⭐ の数・作ったコースは、**その端末の中**に保存されます。
- コースの同期（合言葉）を使ったときだけ、コースが Firebase（Firestore）に保存されます。
- ランキングは、今はその端末だけの記録です。みんなで共有するしくみは用意してあり、Firestore のルールを更新すれば使えます。

## 🛠 ファイル構成（開発メモ）

| ファイル | 中身 |
|---|---|
| `index.html` | ゲーム一覧 |
| `apex-racing.html` | APEX RACING 本体（1ファイルで完結） |
| `turbo-drive.html` | TURBO DRIVE。`apex-racing.html` のアイコン・アプリ名だけを TURBO 用に差し替えたコピー |
| `kids.html` | ドライブがくしゅう |
| `cars/` | 車の3Dモデル（GLB） |
| `assets/` | 道路・空・木・ビルなどの写真素材 |
| `manifest.webmanifest`、`turbo.webmanifest` | ホーム画面アプリの設定（APEX 用・TURBO 用） |
| `icon-*.png`、`turbo-icon-*.png`、`*touch-icon.png` | アイコン |
| `sw.js` | オフラインで遊ぶためのキャッシュ |

- `turbo-drive.html` は、`apex-racing.html` から作るコピーです。直接は直しません。`apex-racing.html` を更新したら、作り直してください。作り直しには、手元の制作フォルダにある `make_turbo_page.py` を使います。
- 素材を差し替えたときは、`sw.js` の `CACHE` の番号を上げてください。上げないと、古いキャッシュが残ります。
